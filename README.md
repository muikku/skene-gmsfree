# Skene for Android without Google Play Services

APK builds of [Skene](https://skene.life) that do not use Google Mobile Services:
package `com.muikku.skene.gmsfree`, no push notifications, GPS-only location.
Details and the other install options: https://skene.life/android

Each [release](https://github.com/muikku/skene-gmsfree/releases) carries the APK,
its SHA-256 and the source commit it was built from. Skene is not open source; the
source lives in a private repository, and this one holds only releases so
[Obtainium](https://github.com/ImranR98/Obtainium) can follow it.
